# Agent design sheet

Use one sheet per agent. Fill it in before writing code.

| # | Question | Your answer |
|---|---|---|
| 1 | **Goal.** In one sentence, what is the agent for? | |
| 2 | **Users.** Who will talk to it, and through what? | |
| 3 | **Read tools.** What does it need to look at? | |
| 4 | **Action tools.** What does it need to change? Which need approval? | |
| 5 | **Limits.** Maximum steps per question? Maximum message length? | |
| 6 | **Must refuse.** What must it never do, even if asked? | |
| 7 | **Memory.** What should it remember during a conversation? Between conversations? | |
| 8 | **Knowledge.** Which documents should it be able to search? | |
| 9 | **Hand over.** When should it pass the conversation to a person? | |

Tip: if you cannot fill in row 4 and row 6 clearly, the agent is not ready
to be built.
